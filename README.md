# PATCHGATE

Advisory-scoped software release gate using GenLayer validator consensus and OSV vulnerability records.

> Development status: source implementation and tests are being prepared. Not deployed or proven on GenLayer Studio yet. This contract is **not** a security certification; an ALLOW decision applies only to the explicitly listed advisories and the exact package/version snapshot.

See `contracts/patchgate.py` for the standalone Intelligent Contract and `docs/STUDIO_ACCEPTANCE.md` for the required real-chain tests.
